SPACE EXPLORER WEBSITE
======================

HOW TO RUN (Windows):
1. Extract Space_Explorer_Website.zip.
2. Open the extracted Space_Explorer_Website folder.
3. Double-click index.html.
4. It opens in your default browser. No Python or installation is required.

FEATURES:
- Responsive space-themed landing page
- Animated solar system illustration
- Clickable cards for all eight planets
- Planet profile, distance, moons, year and fact
- Rotating space facts
- Interactive 5-question quiz with score
- Optional synthesized ambient sound (starts only when clicked)

FILES:
- index.html  : page structure
- style.css   : design and animations
- script.js   : planet data and interactions

NOTE:
Google Fonts require an internet connection for the chosen fonts. The website itself works offline using fallback fonts. Planet data is educational and may change as discoveries are updated.
